Critical algorithms/semantics:

- `models.design(z, model, t)` emits exactly 78 consecutive nominal `k` labels per distinct date and only numeric Z0 or nominal train S0. No same-day R, P0 OPEN, Zret/Zvol/Zchg or additional input enters a fit. Equal unit row weights imply identical 78-unit fitting weight per date.
- `models.transform`: train-only linear quantiles for numeric cuts (7 or 15 internal cuts); train S0 uses linear terciles with ties assigned to upper cell. Means/SD, extrema and five representative quantiles are training-only. Missing Z0 is excluded before all models; unknown/missing native reserves are tested only as software guards, not observed scientific support.
- `models.audit`: exact native term graph, all 78 categorical time mappings (including pair’s effective shared mapping), pair tensor shape, finite unknown/extreme guard, predict=intercept+eval_terms, and pickle predict parity. InterpretML deduplicates identical main/pair categorical bin maps; one stored map can validly serve both. Native best_iteration/bagged_scores/weights are recorded without calling them raw-science uncertainty.
- `m8_softmax.objective(theta,x,q,penalty)`: center 2×78 coefficient rows; daily mean cross entropy plus λ/2 sum(b²), λ=0.001 with no N or 78 penalty divisor. Analytic gradient includes centering projection. L-BFGS-B maxiter=2000, ftol=1e−13, gtol=1e−9, maxls=40; fail on nonconvergence or max gradient>2e−6. 154 identifiable free coefficients; no latent covariance model.
- `select_configurations`: only INNER2018/2019 scores enter; equal mean of each matched additive/interaction pair across both folds; tie within 1e−15 favors A. Independent family minima are not falsely presented as an interaction-controlled comparison. Both pairs selected B; T0 fixed A.
- `checkpoint`: protocol+train/eval date hashes+model+configuration+seed identity, SHA-verified model blob and complete JSON receipt. Missing/invalid completion is not silently accepted. 60 empirical native fits, 3,600 seconds, 4GB process RSS and 300MB C3 retained-output guards apply before a new empirical branch. Actual resume emitted zero FIT lines and created no new models.
- `analysis.score`: daily MSE=mean over78 squared bin errors; MAE; raw half-L1; TV only when prediction is nonnegative (tolerance1e−12) and closed (1e−10). Closing and all windows sum the native raw 78-vector before computing date errors. Raw negatives/closure defects are preserved. `NORM_` is separately named positive-part closure, uniform fallback on zero mass, not an unchanged native model.
- `shape`: whole-response same-observed-row high/low means; H1=sum(delta[66:78]); half-L1=0.5 sum(abs(delta)); D=delta−delta[30]; TV only for valid normalized mean profiles. Last-bin delta[77] plus delta[66:77] sums to primary H1. All point/interval labels retain developmental status.
- Paired loss sign is first−baseline, negative favors first. Calendar HAC uses scheduled-slot Bartlett lags with gaps (existing independently checked C2R function). Joint circular scheduled-slot blocks share each draw across raw/model/paired forecasts; missing dates never receive a fabricated Q. Eligible-order ACF/PACF/ARCH deliberately compress gaps and are separately labeled heuristic.
- Environment reference reweighting fixes 2016–19 D_FULL S0 frequencies, then averages same-state year profiles; it is explicitly a different coarse reference estimand from original marginal Q. 2020 aggregate is ABSTAIN; supported 2021 weighted values were independently reconciled using per-day weights to <1e−10.
